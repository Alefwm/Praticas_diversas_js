# ⚡ Práticas Diversas em JavaScript

Repositório criado para registrar meus estudos, exercícios e experimentos durante minha jornada de aprendizado em **JavaScript**.

Aqui estão reunidas práticas desenvolvidas com o objetivo de transformar conhecimento teórico em código e aprimorar minha lógica de programação.

---

## 🎯 Objetivo

Este repositório tem como objetivo documentar minha evolução no aprendizado de JavaScript por meio de:

- 🧠 Exercícios de lógica de programação
- 💻 Práticas com JavaScript
- 🧩 Resolução de problemas
- 🔍 Testes e experimentos
- 🚀 Pequenos projetos
- 📚 Aplicação dos conceitos estudados
